# Roadmap

## Current vertical slice

- one structured concrete material
- standardized geometry selector and comparison stage
- neutral, overcast, sunlight, and grazing lights
- close-up, medium, and far camera presets
- channel inspection and UV checker
- scale inputs and ruler overlay
- stable seams/repetition warnings
- deterministic macro anti-tiling prototype
- screenshot, state, validation, and ZIP package export

## Next

- add a second materially different surface, beginning with wood, brick, metal, or asphalt
- author true map files instead of runtime estimates
- add source crop and perspective-correction tools
- add searchable material library and variant inheritance
- add robust triplanar and stochastic sampling
- add preview image generation and package index updates
