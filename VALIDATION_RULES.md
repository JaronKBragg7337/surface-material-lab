# Validation Rules

Validation is deterministic where possible and heuristic where visual judgment is required.

Current checks include:

- missing or duplicate material IDs
- missing provenance or license
- missing authored channels versus runtime estimates
- invalid source dimensions or physical scale
- non-seamless sources under repeated mapping
- large-plane repetition
- unvalidated close-up, curved, and vertical use
- invalid roughness and metalness ranges

Heuristic issues are warnings, not proof of failure. A material can be useful at far distance while remaining rejected for close-up use.
