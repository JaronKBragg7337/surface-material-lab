# Urban Surface Source Set 002

Eight additional original photographs from the owner's environment are preserved here under CC0-1.0 at the owner's direction.

The set produces seven material cards because the two pale-paver photographs document the same surface and are kept as alternate captures inside `MAT-STONE-0001`.

The batch includes three asphalt scales, a broadleaf surface, loop-pile carpet, pale weathered pavers, and a crumpled gray textile. Context objects remain in the original files; runtime crops remove them only when they do not belong in the reusable surface map. Physical dimensions remain unverified.
