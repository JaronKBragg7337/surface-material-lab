# Urban Surface Source Set 001

Ten original user-provided photographs preserved for future material cards.

This is an intake set, not a finished material library. Each image remains an unmodified source. The set has no confirmed public asset license yet, so entries use `pending_user_confirmation` rather than being labeled CC0. Physical coverage is also unmeasured.

The first promoted material from this set is `MAT-BRICK-0001`, based on photo 9. The other sources remain candidates for concrete pavers, wood, rock/soil, bark, and brick pavers.
