# Urban Surface Source Set 001

Ten original user-provided photographs preserved for future material cards.

This is an intake set, not a finished material library. Each image remains an unmodified source. The owner has released these user-authored photographs under `CC0-1.0`; physical coverage is still unmeasured.

All ten sources are now represented by cards in the lab. The cards remain prototypes with provisional scale; bark and mixed rock/soil carry additional limitations because their photographs include organic context and are not clean seamless tiles.
