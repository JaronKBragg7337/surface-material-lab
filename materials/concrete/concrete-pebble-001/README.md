# MAT-CONCRETE-0001 · Concrete Pebble

This is the first material card in Surface Material Lab. It is a photographed exposed-aggregate surface used to validate the material pipeline across standard Three.js geometry.

The base-color map is authored from the source photo. Normal, height, and roughness maps are currently estimated in the browser and are explicitly recorded as missing authored maps in `material.json`.

Provisional source scale: **1.00m × 1.00m**. This is unverified until a measurement reference is supplied.
